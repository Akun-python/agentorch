# MGCM Framework

This file provides an ASCII-friendly entry point for the formal design note of the
**Matriarch-Governed Collective Memory Framework (MGCM)**.

For the full Chinese write-up, see:

- `族长治理式群体记忆框架.md`

Recommended formal name:

- Chinese: `族长治理式群体记忆框架`
- English: `Matriarch-Governed Collective Memory Framework`
- Abbreviation: `MGCM`

Core idea:

- supervisor acts as the default matriarch governor
- local agent experience is separated from collective long-term knowledge
- shared working memory stores candidates rather than final truth
- only validated experience is promoted into persistent collective memory
- persistent records allow collective knowledge inheritance across supervisor restarts
